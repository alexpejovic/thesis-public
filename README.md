# Alex Pejovic's Master's Thesis Repository

Here is the list of most relevant directories and what they do:

- `final_plotting`: automatic scripts for generating all plots from the thesis
- `scripts/datagen`: scripts for generating all data (voltage traces, loss
  sweeps, scores)
- `scripts/plotting`: scripts for generating additional plots that are not part
  of the thesis
- `vae`: Equinox models of all the VAEs used in the thesis and in testing
